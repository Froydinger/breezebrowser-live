# Android source

The Android app is maintained in [`Froydinger/BreezeMobile`](https://github.com/Froydinger/BreezeMobile). The `android/` subtree was moved there with its Git history, app source, build configuration, design assets, and QA records. Do not resume Android development in this desktop repository.

The existing signed 0.1.5 beta download remains available from this repository's release asset. Future Android source changes and APK releases belong in `BreezeMobile`; update the separate website lander as described in that repository's `RELEASE.md`.

The Cloudflare chat Worker remains in this repository under `cloudflare/breeze-chat-worker` and is shared with Breeze desktop.
